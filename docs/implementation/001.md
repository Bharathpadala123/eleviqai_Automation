| File | Change |
|---|---|

| `pages/chat/ChatPage.ts` | `giveThumbsDownForFailedRun(testInfo)`: clicks "Bad response", then "Ok" in the dialog, which saves the dislike with no comment (`POST /api/messages/{id}/dislike`, body `comment: null, send_to_elviqai: false`). It waits for that request, checks the button shows as pressed, writes a `Thumbs down (Bad response)` annotation with the message ID and the server's reply, and attaches a screenshot of the rated answer. It never throws, so it cannot change a run's result. If the run failed before an answer appeared, it records "Not clicked". It never clicks an already-pressed button (a second click would undo it) and never types or sends a comment. |
| `pages/chat/ChatPage.ts` | `waitUntilReadyForNextScenario(testInfo)`: a scenario starts at least `SCENARIO_GAP_MS` (default 20000; 0 turns it off) after the previous one finished, and only once `/api/health` answers below 500 (polled every 30 s for up to `HEALTH_MAX_WAIT_MS`, default 15 min). Each wait is added to the test timeout. A health wait is written to the report as `Environment wait before the scenario`. The finish time is kept in a temp file because Playwright starts a new worker after each failed test. |
| `step-definitions/chat/chat.steps.ts` | `Before` hook calls the pacing/health wait; `After` hook gives the thumbs down when the run `failed` or `timedOut`, then records the finish time. Passed runs are not rated. |
